# ED-03: Adopt the Master Project Brief's decision-record format

**Status:** Accepted (Milestone 1)

## Context

We needed a consistent way to record decisions so the team can see why something was chosen.

## Alternatives considered

- No formal record
- A full custom template
- The format given in the Master Project Brief

## Decision

Use the Master Project Brief's decision-record fields (Context, Alternatives considered, Decision, Rationale, Trade-off/risk) for every significant decision going forward.

## Rationale

Keeps decisions traceable without inventing our own format from scratch.

## Trade-offs / risks

Extra documentation effort per decision — could get skipped under time pressure if we're not disciplined about it.
